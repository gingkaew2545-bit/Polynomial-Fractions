ห้องทดลองเศษส่วนพหุนาม

ทดลองปรับค่า สังเกตกราฟ และค้นพบว่าเหตุใดการตัดตัวประกอบจึงต้องระวังค่า x ที่ทำให้ส่วนเป็นศูนย์

เป้าหมายการเรียนรู้

ทดลอง

ปรับค่าตัวแปร a และสังเกตการเปลี่ยนแปลงของนิพจน์

สังเกต

เปรียบเทียบค่าของเศษส่วนพหุนามก่อนและหลังการแยกตัวประกอบ

วิเคราะห์

อธิบายค่าที่ห้ามใช้และจุดที่ขาดหายไปบนกราฟ
กิจกรรมที่ 1 • ทดลองปรับค่า

เศษส่วนพหุนามเปลี่ยนไปอย่างไร?

พิจารณาเศษส่วนพหุนามรูปแบบนี้ แล้วปรับค่า a ด้วยแถบเลื่อน

(x² − 9) / (x − 3)
เลื่อนเพื่อเปลี่ยนจำนวน a ตั้งแต่ −5 ถึง 5

แยกตัวประกอบ
(x − 3)(x + 3) / (x − 3)
= x + 3 เมื่อ x ≠ 3
ข้อควรสังเกต

ตัวส่วนเป็นศูนย์เมื่อ x = 3 ดังนั้น x ≠ 3

แม้ตัดตัวประกอบได้ แต่ค่า x ที่ทำให้ตัวส่วนเดิมเป็นศูนย์ยังใช้ไม่ได้

กิจกรรมที่ 2 • สังเกตกราฟแบบเรียลไทม์

กราฟก่อนและหลังการตัดตัวประกอบ

เส้นกราฟแสดงความสัมพันธ์ y = x + a ส่วนวงกลมโปร่งแสดงตำแหน่งที่ขาดหายไป เพราะเศษส่วนเดิมหาค่าไม่ได้เมื่อ x = a

กราฟ y = x + a จุดที่ไม่กำหนด (รูโปร่ง)

เมื่อ a = 3 กราฟเป็นเส้นตรง y = x + 3 แต่เว้นจุด (3, 6) ไว้

สรุปความรู้

สิ่งที่ค้นพบ

  1. ใช้ผลต่างกำลังสอง: x² − a² = (x − a)(x + a)
  2. ดังนั้น (x² − a²)/(x − a) = x + a เมื่อ x ≠ a
  3. การตัดตัวประกอบไม่ทำให้เงื่อนไขของตัวส่วนเดิมหายไป จึงต้องระบุค่าที่ห้ามใช้เสมอ
จำไว้: เศษส่วนพหุนามต้องมีตัวส่วนไม่เท่ากับศูนย์
ประเมินความเข้าใจ • 3 ข้อ

ลองตอบคำถามท้ายกิจกรรม

1. เศษส่วนพหุนาม (x² − 16)/(x − 4) มีค่าเท่ากับข้อใด เมื่อ x ≠ 4?
2. จากเศษส่วน (x² − 25)/(x − 5) ค่าใดเป็นค่าที่ห้ามใช้?
3. เหตุใดกราฟของ (x² − 9)/(x − 3) จึงมีจุดขาดหายที่ x = 3?

เฉลยพร้อมเหตุผล
  1. ข้อ 1: x + 4 เพราะ x² − 16 = (x − 4)(x + 4) แล้วตัดตัวประกอบร่วมได้ เมื่อ x ≠ 4
  2. ข้อ 2: x = 5 เพราะทำให้ตัวส่วน x − 5 เป็นศูนย์
  3. ข้อ 3: ตัวส่วนมีค่าเป็นศูนย์ เมื่อ x = 3 เศษส่วนเดิมจึงไม่มีนิยาม แม้จะย่อรูปได้เป็น x + 3 ก็ตาม
